## 1. Regeln für jedes Gespräch

1. Über Vergangenheit fragen, nicht über Zukunft. "Wann zuletzt ...?" statt "Würdest du ...?"
2. Kein Pitch vor Minute 25. Produktidee erst im Schlussblock, und nur als Preisanker-Reaktion.
3. Komplimente und Absichtserklärungen ("klingt super", "würde ich kaufen") notieren, aber als **kein Signal** werten.
4. Jede Aussage zu Geld oder Aufwand konkretisieren: Was, wann, wie viel, wo gekauft?
5. Schweigen aushalten. Nachfragen: "Erzähl mal genauer", "Was hast du dann gemacht?"
6. Wenn möglich Beweis ansehen: Foto vom Kühlschrank, von der Deckelschublade, vom Käsefach (nur mit Einwilligung, nicht speichern ohne Datenschutzklärung, siehe Backlog #17).
7. Keine Frische- oder Wirkversprechen machen, auch nicht mündlich (`playbook/fixed.md`, Recht).

## 2. Screener (vor dem Termin, 2 Minuten)

Ziel: pro Job die richtige Person, keine Gefälligkeitsinterviews.

| Frage | H1 Obst/Gemüse | H2 Käse | H6 Deckelsystem |
|---|---|---|---|
| Haushaltsgröße | 2 bis 4 Personen | egal | Familie oder Meal-Prep |
| Einkaufsmuster | Wochenmarkt, Bio-Kiste oder großer Frischeeinkauf mindestens wöchentlich | 3 oder mehr Käsesorten gleichzeitig im Kühlschrank, Kauf an der Theke | kocht vor oder bewahrt Reste regelmäßig in Dosen auf |
| Ausschluss | arbeitet in Haushaltswaren, Handel mit Aufbewahrung oder bei Eshop Guide | wie links | wie links |

Pro Person höchstens zwei Jobs im Gespräch, sonst wird es flach. Engste Bekannte meiden; Kollegen nur, wenn sie das Screening erfüllen, und dann in der Auswertung markieren.

## 3. Ablauf (45 Minuten)

| Block | Minuten | Inhalt |
|---|---|---|
| A Einstieg | 5 | Kontext Haushalt, Einkauf, Kühlschrank. Einwilligung Notizen/Aufnahme |
| B Job-Modul 1 | 15 | H1, H2 oder H6 (Abschnitt 4) |
| C Job-Modul 2 | 10 | optional zweiter Job |
| D Ausgaben und Alternativen | 8 | Abschnitt 5 |
| E Schluss mit Anker | 5 | Abschnitt 6 |
| F Empfehlung | 2 | "Wen kennst du, der das Problem noch stärker hat?" |

### Block A: Einstieg

- "Beschreib mal, wie euer Wocheneinkauf abläuft. Wer kauft, wo, wie oft?"
- "Wenn du jetzt den Kühlschrank aufmachst: Was siehst du? Wie ist er sortiert?"
- "Was nervt dich an eurem Kühlschrank oder an der Aufbewahrung am meisten?" (offen lassen, **nicht** in Richtung eines Jobs lenken. Nennt die Person spontan einen der drei Jobs, ist das ein starkes Signal; notieren.)

## 4. Job-Module

### H1 Obst und Gemüse

Kritischste Annahme (Karte H1): Glas und Design rechtfertigen etwa das 3- bis 4-fache eines Kunststoff-Produce-Keepers.

1. "Wann hast du zuletzt Obst, Gemüse oder Kräuter weggeworfen? Was genau war es?"
2. "Wie ist es dazu gekommen? Wo lag es, wie war es verpackt?"
3. "Was hast du danach anders gemacht?" (Workaround: Tüte, Küchenpapier, Originalschale, Glas mit Wasser, Box)
4. "Welche Produkte hast du dafür schon gekauft? Wie heißen sie, was haben sie gekostet, wo gekauft, nutzt du sie noch?" (Tupperware KlimaOase, OXO GreenSaver, Rotho Fresh, IKEA o. Ä., nur nennen, wenn die Person nicht selbst darauf kommt)
5. "Was stört dich an dieser Lösung?" Nachfragen: Platz im Gemüsefach, Sichtbarkeit, Nässe, Reinigung.
6. "Wie viel Platz nimmt das im Gemüsefach ein? Passt es?" (Hinweis für Backlog #14)
7. "Welche Sorten verderben am schnellsten? Was kosten die ungefähr pro Einkauf?" (Verderb in Euro greifbar machen)

**Falsifikationssignal:** Die Person hat eine günstige Lösung, nutzt sie und nennt keinen konkreten Mangel. Oder Verderb wird als "passiert halt" ohne Handlung beschrieben.

### H2 Käse

Kritischste Annahme (Karte H2): Käseliebhaber sind ausreichend groß und über Interessen erreichbar. Gegenhypothese: Genießer nutzen Käsepapier, Nicht-Genießer zahlen keine 79 €.

1. "Welche Käsesorten hast du gerade im Kühlschrank? Wie sind sie verpackt?"
2. "Wann hast du zuletzt Käse weggeworfen oder abgeschnitten, weil er ausgetrocknet, schwitzig oder schimmlig war? Welcher Käse, welcher Preis ungefähr?"
3. "Wann hat zuletzt jemand im Haushalt über Käsegeruch im Kühlschrank geklagt? Was wurde dann gemacht?"
4. "Wie bewahrst du Käse auf? Seit wann so? Wie bist du darauf gekommen?" (Folie, Käsepapier, Originalverpackung, Käseglocke, Mepal, Tupperware, Kilner)
5. "Was hast du dafür schon gekauft? Name, Preis, nutzt du es noch?"
6. "Was stört dich daran?" Nachfragen: Kondenswasser, Geruch, Reinigung, Platz, Servieren.
7. "Kaufst du Käse auch als Geschenk oder für Gäste? Wann zuletzt?" (Geschenkkontext, Karte H2 Kleinster Test)
8. "Wo informierst du dich über Käse? Theke, Accounts, Newsletter, Foren?" (Erreichbarkeit)

**Nicht sagen:** "luftdicht", "bleibt länger frisch", "kein Austrocknen" (Verbraucherzentrale rät von luftdichter Lagerung ab, siehe `learnings.md`).

**Falsifikationssignal:** Käsepapier oder Glocke gilt als "reicht völlig"; Verlust nur bei günstigem Käse; kein Geruchskonflikt im Haushalt.

### H6 Deckel und System

Kritischste Annahme (Karte H6): Menschen zahlen deutlich mehr als bei IKEA für die Zusage, dass das System über Jahre passt und reparierbar bleibt.

**Deckelinventar (möglichst mit Foto, sonst Schätzung markieren):**

| Zählfeld | Anzahl | gezählt / geschätzt |
|---|---|---|
| Dosen gesamt | | |
| Deckel gesamt | | |
| Deckel ohne passende Dose | | |
| Dosen ohne passenden Deckel | | |
| Verschiedene Serien/Marken | | |

1. "Wann hast du zuletzt eine Dose gebraucht und keinen passenden Deckel gefunden? Was hast du dann gemacht?"
2. "Wann ist zuletzt ein Deckel oder eine Dose kaputtgegangen? Was ist passiert, was hast du danach gekauft?"
3. "Hast du schon einmal gezielt einen Ersatzdeckel gesucht oder gekauft? Wo, was hat er gekostet, hat es geklappt?"
4. "Hast du schon einmal ein ganzes Set ersetzt, weil Teile nicht mehr passten? Welches, für wie viel?"
5. "Wie oft sortierst du die Schublade oder das Fach aus? Wann zuletzt?"
6. "Wenn du heute neu kaufen würdest: Wo schaust du zuerst?" (IKEA 365+, Joseph Joseph, Pyrex, Discounter; nur nachfragen, nicht vorschlagen)

**Falsifikationssignal:** Wenige lose Deckel, Ersatz per IKEA-Nachkauf gilt als problemlos, kein Ärger im Alltag.

## 5. Block D: Ausgaben und Alternativen (für alle Jobs)

- "Was hast du in den letzten 12 Monaten insgesamt für Dosen, Boxen oder Aufbewahrung ausgegeben? Woran erinnerst du dich konkret?"
- "Was war der teuerste Aufbewahrungskauf, an den du dich erinnerst? Warum hast du dafür mehr bezahlt?"
- "Gibt es etwas, das du gekauft und wieder aussortiert hast? Warum?"
- "Hast du mal nach einer besseren Lösung gesucht, online oder im Laden? Was hast du gefunden, warum nicht gekauft?"

Aktive Suche ohne Kauf ist ein stärkeres Signal als bloßer Ärger.

## 6. Block E: Schluss mit Preisanker (erst ganz am Ende)

Nur einen Job pro Person, den mit dem stärksten Signal im Gespräch. Konzept neutral beschreiben, keine Leistungsversprechen. Beschreibung wörtlich vorlesen:

- H1: "Ein Set aus drei Glasbehältern in zwei Grundflächen fürs Gemüsefach, mit herausnehmbarem Abtropfkorb und einstellbarer Belüftung, plus Kräutereinsatz."
- H2: "Eine flache Glasbasis mit zwei bis drei herausnehmbaren Fächern für verschiedene Käsesorten und einem Deckel, bei dem man die Luftzufuhr einstellen kann. Man kann sie auch auf den Tisch stellen."
- H6: "Ein Glasdosensystem auf zwei Grundflächen mit wenigen Deckelformaten. Deckel und Dichtungen kann man über Jahre einzeln nachkaufen."

Dann:
1. "Was davon würdest du wirklich nutzen, was nicht?"
2. "Womit vergleichst du das spontan?" (zeigt den mentalen Preisanker)
3. Testpreis aus der Karte nennen (H1: 69 € oder 89 €, abwechselnd je Interview; H2: 79 €; H6: 89 € oder 119 €, abwechselnd). "Wie wirkt dieser Preis auf dich?"
4. Commitment-Frage mit echter, kleiner Handlung: "Sollen wir dich benachrichtigen, wenn es einen Prototyp zum Anfassen gibt?" Nur fragen, wenn eine Warteliste mit Double Opt-in existiert (`playbook/fixed.md`). Sonst: "Darf ich dich für einen Prototyp-Test in ein paar Wochen noch einmal anrufen?"

Preisreaktionen im Interview messen Aussagen, kein Verhalten (Claude-Evidenzprüfung, Abschnitt 5, Van Westendorp). Sie fließen nur als schwaches Signal in die Auswertung.

## 8. Auswertung für D1 und Gate 1 (Vorschlag, Patrick entscheidet)

| Signal | Stärke | H1 | H2 | H6 |
|---|---|---|---|---|
| Problem spontan in Block A genannt | stark | | | |
| Konkreter Vorfall in den letzten 4 Wochen | mittel | | | |
| Geld für eine Lösung ausgegeben (Produkt benannt) | stark | | | |
| Aktiv nach besserer Lösung gesucht | stark | | | |
| Bestehende Lösung mit konkretem, benanntem Mangel | mittel | | | |
| Commitment (Rückruf/Opt-in) | mittel | | | |
| "Reicht völlig" zur günstigen Alternative | Gegensignal | | | |
| Interviews gesamt | | | | |
